# Frontend Lab

One Astro project where each section is a self-contained experiment. Page
through them with ← / → (or swipe). Each section is its own route, so leaving
one tears down its framework and animations.

Live: https://adomyne.github.io/Digit-Fruition-experiment/ (rebuilt and
published by `.github/workflows/deploy.yml` on every push to `main`).

```sh
pnpm install
pnpm dev        # http://localhost:4321
```

Rules for humans and agents: [AGENTS.md](AGENTS.md).

Site plan (sitemap, landing page section order, what the stack comparison
covers): [docs/site-structure.md](docs/site-structure.md).
